# opencode-chat-cost

Плагин для [opencode](https://opencode.ai) (CLI и Desktop): по команде `/otchet` показывает, сколько токенов израсходовано в текущем чате, сколько это стоит в рублях (цены задаёте вы) и краткое описание того, что делалось в чате. По желанию публикует отчёт комментарием в Jira.

Проверено на opencode **1.19.0** (V1-сборка плагинов).

## Что делает `/otchet`

1. **Таблица токенов**: input, output, cache read, cache write — сумма по всем ответам модели в чате.
2. **Расход в рублях** — если заданы цены (см. «Цены» ниже): input и output считаются раздельно, cache — по опциональным отдельным ценам.
3. **Связное описание работы в 1–3 предложениях** — модель пишет его на основе истории чата (запросы пользователя, затронутые файлы) в момент вызова команды. Дополнительный запрос к модели не делается.
4. **Предложение отправить отчёт в Jira**:
   - если при вызове указан ключ задачи (`/otchet PROJ-123`) — предложит её;
   - если ключ задачи встречался в этом чате (например, вы создавали `ABC-123`) — предложит её же;
   - иначе спросит, к какой задаче отправить;
   - **без вашего явного подтверждения комментарий не публикуется** — сначала показывается текст, который уйдёт в Jira. Публикация идёт через подключённый MCP-сервер `atlassian` (mcp-atlassian).

## Как это устроено

- Плагин регистрирует инструмент `chat_cost` и команду `/otchet` (через config-хук).
- Инструмент читает историю сессии через SDK opencode и суммирует токены из assistant-сообщений, собирает запросы пользователя и затронутые файлы. Никакие данные наружу не отправляются.
- Публикацию в Jira выполняет агент через MCP-инструмент jira — плагин только формирует задание в шаблоне команды.

## Установка

### 1. Получить код плагина

```bash
git clone https://github.com/egor-sh/opencode-chat-cost.git ~/opencode-chat-cost
```

Либо скопировать каталог целиком с машины, где он уже работает (достаточно `src/`, `package.json`, `tsconfig.json`; `node_modules` можно не копировать). Рекомендуется постоянное место вида `~/opencode-chat-cost`, а не временная папка.

### 2. Установить зависимости

```bash
cd ~/opencode-chat-cost && npm install
```

Сборка не нужна — opencode (на базе bun) исполняет TypeScript-плагины напрямую.

### 3. Подключить плагин

В `~/.config/opencode/opencode.json` (глобально, для всех проектов) или в `opencode.json` проекта:

```json
{
  "plugin": [
    "~/opencode-chat-cost"
  ]
}
```

Для этой V1-сборки путь указывается **на каталог плагина** (не на файл). Также работает формат с опциями:

```json
{
  "plugin": [
    ["~/opencode-chat-cost", { "inputPrice": 500, "outputPrice": 2000 }]
  ]
}
```

### 4. Цены (опционально)

Цены — в рублях за 1 миллион токенов. Два способа:

**Способ А — файл `chat-cost.json`** (рекомендуется, не зависит от формата конфига):

```bash
cp ~/opencode-chat-cost/chat-cost.example.json ~/opencode-chat-cost/chat-cost.json
```

```json
{
  "inputPrice": 500,
  "outputPrice": 2000,
  "cacheReadPrice": 50,
  "cacheWritePrice": 625,
  "currency": "₽"
}
```

Файл ищется в каталоге `src/` плагина и в корне плагина. Личные цены (`chat-cost.json`) не коммитятся — есть в `.gitignore`.

**Способ Б — options в конфиге**: формат `[ "путь", { "inputPrice": 500, "outputPrice": 2000 } ]` (проверено на 1.19.0 — опции передаются в плагин).

Опции плагина:

| Опция | Описание | По умолчанию |
|---|---|---|
| `inputPrice` | руб. за 1M input-токенов | не задана — стоимость не считается |
| `outputPrice` | руб. за 1M output-токенов (включая reasoning) | не задана |
| `cacheReadPrice` | руб. за 1M cache read-токенов | 0 |
| `cacheWritePrice` | руб. за 1M cache write-токенов | 0 |
| `currency` | символ валюты в отчёте | `₽` |

Если цены не заданы ни одним способом, отчёт показывает только токены.

### 5. Перезапустить и проверить

```bash
opencode debug config | grep otchet   # команда зарегистрирована
```

Затем перезапустить opencode и выполнить `/otchet` в любом чате.

## Перенос на другой ПК

1. Скопировать каталог плагина (без `node_modules` и без личного `chat-cost.json`) в постоянное место, например `~/opencode-chat-cost/`.
2. `cd ~/opencode-chat-cost && npm install`.
3. Прописать в `~/.config/opencode/opencode.json`:
   ```json
   "plugin": [ "~/opencode-chat-cost" ]
   ```
4. Скопировать личный `chat-cost.json` (цены) — если используете.
5. Для публикации в Jira — перенести блок `mcp.atlassian` из `opencode.json` (URL + персональные токены Jira/Confluence). Без него отчёт работает, но шаг публикации не выполнится.
6. Перезапустить opencode, проверить `opencode debug config | grep otchet` и вызвать `/otchet`.

## Jira

Требуется подключённый в opencode MCP-сервер `atlassian` (например, `uvx mcp-atlassian` с переменными `JIRA_URL`, `JIRA_PERSONAL_TOKEN`). Проверить доступность: при старте opencode в логе не должно быть `server unavailable key=atlassian`.

## Устранение неполадок

- **Команды `/otchet` нет** — перезапустить opencode (команды подхватываются при старте). Проверить: `opencode debug config | grep otchet`.
- **Плагин не загрузился** — смотреть лог: `grep "failed to load" ~/.local/share/opencode/log/opencode.log`. Частая причина у самописных плагинов: в модуле должны экспортироваться только сами плагины; любые именованные function-экспорты opencode 1.x вызывает как отдельные плагины. В этом плагине оставлен только `export default`.
- **«Стоимость не считается»** — не заданы цены (способ А или Б из раздела «Цены»).
- **Комментарий в Jira не уходит** — не подключён MCP `atlassian`, либо вы не подтвердили отправку (подтверждение обязательно по дизайну).

## Сборка из исходников

Не требуется. Для публикации в npm при желании: `npm install && npx tsc` (в `package.json` тогда вернуть `main`/`exports` на `dist/`).
